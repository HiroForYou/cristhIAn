Chatbot médico Unimedic 🤖💬

Idea: La idea que motivó el desarrollo del proyecto fue facilitar el análisis médico a pacientes y doctores, evitando citas médicas innecesarias.

PytorchFastAPIReact Native
Demo en vivo Código Medtorch

Motivación

Este proyecto se basó en el repositorio medtorch (ganador del hackathon de Pytorch 2020). Tanto la aplicación como el despliegue fueron procesos muy interesantes, que nos mostraron de forma desafiante cómo podíamos atacar problemas del mundo real con la ayuda de distintas herramientas de Deep Learning.

Funcionalidades

  • ⚛️ Interfaz creada con React-Native.
  • 🍃 Autenticación con Mongo DB.
  • 🌀 Chatbot impulsado por GiftedChat.
  • 🔥 Backend potenciado con modelos construidos en PyTorch.

Instalación y configuración

Sigue estos pasos para configurar tu entorno de React Native. También te recomiendo seguir este tutorial para configurar bien Android Studio. Para conectar sin problemas tu celular y/o emulador, necesitas instalar ADB y configurar tus variables de entorno.

Una vez que hayas instalado los paquetes con npm i, puedes ejecutar el siguiente comando:

npm start

Esto abrirá automáticamente Expo en tu navegador. Te recomiendo usar Expo Go para correr la app directamente en tu celular sin usar el cable USB.
